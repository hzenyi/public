1. 這是什麼

一座放在你電腦上的 Obsidian 筆記庫，加上一群會讀懂它的 AI 助手。你把事情交辦下去，AI 依庫裡的規則與技能完成，並把軌跡記下來。這個系統的名字叫「小正」。

關於「小正」：小正是這座第二大腦的名字，指筆記庫、規則、技能，以及在庫裡替你工作的 AI 助理（不分 Claude、Codex 或 Antigravity）。可以直接說「小正，開工」「請小正幫我整理成公告」。小正是助理，不是真人，也不是某個模型的名稱；取名不改變任何規則，不編造、資訊不全先問、個資代號化、不可逆動作先確認。規則寫在 90_Core/identity.md。

儲存層

全部是純文字 Markdown 檔，存在本機，不用封閉資料庫。任何工具都讀得懂。

資料層

PARA 分類加六大領域，檔案之間用 [[雙向連結]] 串起來，每份筆記都有 YAML 欄位。

智慧層

AI 當「維護工程師」：攝入整理、語意檢索、自動修復，並從你的重複工作裡長出新技能。

誰在用這座庫

Claude Code、Codex、Antigravity 三個 AI 工具共用同一份設定。所以任何新增的記憶、規則、技能，都必須讓三者都能用，這是庫裡的最高原則。

AI 開工前一定先讀：AGENTS.md，再讀 90_Core/ 裡的全部設定檔（身分、風格、規則、參數、公開發布規則、小正的名字）。你不用每次提醒。

2. 每天怎麼用

不用記指令，用平常說話的方式交辦即可。以下是最常見的節奏。

  1. 開工：說「小正，開工」或輸入 /today，AI 建立今天的日誌 50_Daily/YYYY-MM-DD.md，並把前一份沒做完的待辦帶進來。
  2. 丟資料：臨時想法、名單、逐字稿、剪藏，直接丟進 00_Inbox/，再說「幫我清洗 Inbox 並歸檔」。
  3. 交辦事情：用自然語言說，例如「幫我整理成 LINE 公告」「幫我寫一份簽」。AI 會自動挑對應的技能。
  4. 記想法：以「閃念：」開頭說出來，AI 存成閃念卡片，之後再慢慢升級成永久卡片。
  5. 收工前：AI 已經把今天交辦的事寫進日誌。需要時雙擊 git-sync.bat，把變更同步到 GitHub。
  6. 每週六：週復盤。AI 掃過去 7 天的日誌，把重複 3 次以上的工作提議做成技能。

一件事怎麼流動

你說一句話→ AI 讀 AGENTS.md 與 90_Core→ 挑技能執行→ 成品放到規定位置→ 寫入當日日誌與 log.md
資訊不全時，AI 會先問，不會猜。時間、地點、數據、文號、人名一律不編造。

    全部寫在 90_Core/，AI 開工前先讀。

    必須遵守的安全守則

    不直接刪除

    廢棄內容只能移到 40_Archives/。要刪檔先經你同意。

    個資代號化

    學生寫「甲生」「座號 01」，教師寫「A 師」。不寫身分證、住址、電話、家長帳戶。

    金鑰不入檔

    API Key、Token、密碼一律用環境變數，不寫進任何檔案。

    不可逆先確認

    刪除、覆蓋、發送、DROP／TRUNCATE 等操作，先問你。

    紅線事件

    性平／兒少事件 24 小時內通報；利益迴避；不利處分要給陳述意見並附救濟教示。

    6. 工具與同步

    放在 70_Script/，在 PowerShell 裡進入該資料夾，用 .\名稱.bat 執行；也可以直接雙擊。AI 只負責寫，執行由你在本機進行。

    git-sync

    第一次執行會初始化 git 並連到私人 GitHub 倉庫；之後列出變更，按 Enter 確認即推送。加 -DryRun 只列出不動作。

    sync-claude-skills

    把 .agents/skills 單向同步到 .claude/skills。先列差異、確認才複製、舊檔備份到 40_Archives/skill-sync-backup/。

    publish-html

    把 80_Publish/ 的頁面推送到公開倉庫，詳見下一節。

    外部連結（Connectors）

    在 claude.ai 連結你的帳號後，小正可以讀寫 Google 行事曆（新增、修改、刪除前會先請你確認），也可以在授權後直接推送 GitHub。

    這些工具都不刪檔，覆蓋前會先列清單並備份。參數 -DryRun 只列出、-Yes 略過詢問。

    同步到 GitHub 與在另一台電腦使用

    私人庫放在 GitHub 的 Private 倉庫。日常雙擊 git-sync.bat 同步（提示直接按 Enter 即確認）。在另一台電腦用 git clone 複製下來、用 Obsidian 開啟、把資料夾連給 AI 工具，就能得到同一個小正；密碼與金鑰不放在庫裡，要在新電腦另外設定。

    日誌與紀錄

    50_Daily/ 記每天交辦的事；log.md 記設定、規則、工具的異動；index.md 是全庫地圖。AI 會自動維護這三者。

    7. 公開發布

    想把 AI 做的 HTML 放上公開網頁時，走這條流程。

    1. 請 AI 製作頁面。草稿先放 00_Inbox/。
    2. AI 依 publish-rules.md 做公開前檢查：真實姓名中間字換成 ○；班級、座號、市內電話可公開；手機只留前 4 碼其餘為 X；沒有內部網址、帳密、未公告事項。
    3. 你確認可公開後，AI 建立 80_Publish/YYYYMMDDNN/（NN 是當天流水號，01 起算），主檔叫 index.html，圖片等放同一資料夾，並登記在 publish-log.md。同一份頁面修改後重新發布，沿用原資料夾，不佔新編號。
    4. 執行 publish-html.bat 推送，或請 AI 直接推送。
    5. 網址是 公開網站網址 + 資料夾名稱 + /，網站網址記在 PRM-GIT-003。
    第一次設定公開網站：在 GitHub 建立名為 public 的公開倉庫，到 Settings → Pages，Source 選「Deploy from a branch」，Branch 選 main、資料夾 / (root)。公開倉庫的首頁 index.html 會由工具自動重建，列出所有頁面。
    撤下頁面：不是直接刪除。整個資料夾移到 40_Archives/published-html/，在 publish-log.md 標註已撤下，並同步移除公開倉庫裡的資料夾。已用過的編號不重用。

    8. 常見問題

    AI 沒照規則做怎麼辦？

    先確認它有讀 AGENTS.md 與 90_Core/，沒有就請它重新讀。仍有問題，到對應檔案修規則，不要只在對話裡口頭交代。

    怎麼新增一個全域規則？

    寫成 90_Core/ 裡的獨立 Markdown，再到 AGENTS.md 第 0 節加說明與 @ 引用。這樣三個 AI 工具都讀得到。

    怎麼新增一個技能？

    說「提煉技能」讓 AI 從重複的工作長出來，或用「專案包建造器」一步步做。技能要同時放 .agents/skills/ 與 .claude/skills/。

    重複的工作會自動變成技能嗎？

    不會自動。7 天內同類工作重複 3 次以上，AI 會在總結時提議，你同意才建立。你拒絕的提議不會再提。

    在 PowerShell 執行 .bat 說找不到？

    要加 .\，例如 .\git-sync.bat。PowerShell 預設不從目前位置載入指令。

    可以讓 AI 直接推送到 GitHub 嗎？

    可以，前提是你在 claude.ai 連結了 GitHub 並授權該倉庫。日常同步私人庫仍建議雙擊 git-sync.bat。

    放在 GitHub 的私人庫裡有個資怎麼辦？

    倉庫務必設成 Private。庫內已規定個資代號化、金鑰不入檔；公開倉庫只放通過公開檢查的成品。

    「小正」是真人或某個模型的名字嗎？

    都不是。小正是這座第二大腦的名字，由 Claude、Codex、Antigravity 共同使用。問「你是誰」或「用什麼模型」時，AI 會照實說明實際使用的工具與模型。

    怎麼在另一台電腦設一個一樣的小正？

    先在這台執行 git-sync.bat 推上最新內容；到另一台安裝 Git 與 Obsidian，git clone 私人倉庫，用 Obsidian 開啟，再把資料夾連給 AI 工具。之後兩台都用 git-sync.bat 保持一致，並避免同時改同一個檔案。

    改了檔案要不要更新 YAML？

    要。修改時保留並更新頂部的 tags、date、updated、type。
