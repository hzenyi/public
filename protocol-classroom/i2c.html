01 · 認識 I2C

01什麼是 I2C？

I2C（Inter-Integrated Circuit，唸作 I-squared-C，也常寫作 IIC）是一種只用兩條線就能連接很多顆裝置的同步序列匯流排，感測器、OLED 顯示器、即時時鐘模組常常都是用它跟主控板溝通。跟 UART 最大的不同：I2C 有一條共用的時脈線 SCL，收發雙方跟著同一個節奏走，不用像 UART 一樣事先講好鮑率。

UART（上一堂課）

點對點連接，兩顆裝置各自的 TX/RX 交叉接；非同步，靠事先講好的鮑率對齊時間；一條線同時間只能接一組裝置。

I2C（這堂課）

匯流排式連接，所有裝置共用同一組 SDA/SCL；同步，靠 SCL 時脈對齊；可以在同一組線上接很多裝置，用位址分辨彼此。

02 · 接線與匯流排

02SDA / SCL 與提升電阻

I2C 只有兩條線：SDA（Serial Data，資料線）負責傳資料，SCL（Serial Clock，時脈線）負責提供節奏，所有裝置都掛在同一組線上（稱為「匯流排」）。這兩條線都是開洩極（Open-drain）輸出：裝置只能把線「拉低」，沒辦法主動把線「拉高」，所以一定要外接提升電阻（Pull-up Resistor）接到電源，線路閒置時才能回到高電位。

03 · 共地是關鍵

03就算接對 SDA/SCL，也要共地

高低電位是相對於 GND（0V 參考）來判斷的。就算 SDA、SCL 接得完全正確，只要主機和裝置沒有共用 GND，兩邊對「多少電壓算 1、多少算 0」的認知就會不一樣，訊號一樣可能被誤判。按下按鈕，實際比較「有共地」跟「沒共地」的差別：

04 · START / STOP

04START 與 STOP 條件

I2C 沒有額外的「起始位元」，而是用 SDA 和 SCL 兩條線的相對變化來表示一次通訊的開始與結束：SCL 保持高電位時，若 SDA 由高變低就是 START；若 SDA 由低變高就是 STOP。正常傳送資料位元時，SDA 只能在 SCL 是低電位時改變，這樣才不會被誤判成 START 或 STOP。

05 · 定址與應答

05位址、讀寫與 ACK

START 之後，主機會先送出7 個位元的裝置位址（A6～A0，例如 OLED 是 0x3C），再加 1 個讀寫位元 R/W（0 = 寫入、1 = 讀取）。匯流排上所有裝置都會聽到，只有位址相符的裝置會回應：把 SDA 拉低送出 ACK（應答），表示「我在這裡，收到了」；如果沒有人回應，SDA 會維持高電位，稱為 NACK。
