01 · 認識 USB

01什麼是 USB？

USB（Universal Serial Bus，通用序列匯流排）是電腦與周邊之間最常見的有線連接標準，滑鼠、鍵盤、隨身碟、手機充電、Arduino 燒錄都靠它。和 UART 最大的差別是主從式：所有通訊都由主機（Host）發起，裝置（Device）只能被問了才回答。一個 Host 最多可管理 127 個裝置，靠集線器（Hub）用樹狀方式擴充。

02 · 線材與接腳

02USB 的四條線

USB 2.0 的線材只有四條：VBUS（+5 V 電源，紅）、D−（資料負端，白）、D+（資料正端，綠）、GND（接地，黑）。電源和資料走同一條線，所以插上去就能供電又能通訊。裝置在完成設定前最多取用 100 mA，設定後最多可申請 500 mA。

03 · 差動訊號

03為什麼要用 D+ 和 D−？

USB 2.0 不看單一條線的電壓，而是看D+ 減 D− 的差。外界雜訊（馬達、手機電磁波）會同時打在兩條緊貼的線上，相減之後就抵消了。拉動雜訊滑桿，比較「只看 D+」和「看 D+ − D−」的判讀結果。

04 · 編碼模擬

04資料怎麼送上線：NRZI 與位元填充

USB 沒有獨立的時脈線，接收端得從資料本身找節奏。做法是 NRZI 編碼：差動線有兩種狀態，叫 J 與 K。傳 0 時狀態翻轉，傳 1 時維持不變，線路閒置時停在 J。連續太多個 1 就沒有翻轉，所以每連續六個 1 之後要強制插入一個 0（SYNC 最後那個 1 也要算進去），這叫位元填充。資料從最低位元（LSB）先送。封包以 SYNC 開頭、以 EOP 結尾，EOP 的主體是 SE0（D+、D− 同時拉低），要維持 2 個位元時間。選一個位元組，按「送出」逐格播放。文中有虛線底線的字可以點，下面的名詞小卡也能查。

05 · 封包與交易

05封包（Packet）與交易

USB 的資料會包成封包（Packet），每個封包都以 SYNC 開頭、以 EOP 結尾（上一頁看過了）。Host 完成一件事，叫一次交易（Transaction），通常由三個封包組成：Token（Host 說要做什麼）→ Data（資料）→ Handshake（回報結果）。每個封包用 PID 說明自己是哪一種，Token 還會指定對象：哪個位址的裝置、哪個端點。先選封包類型，再點方塊看每個欄位的意義。文中有虛線底線的字可以點，下面的名詞小卡也能查。

06 · 列舉

06列舉（Enumeration）

裝置插上去的瞬間，Host 其實完全不認識它。列舉就是 Host 一步一步讀取裝置的描述元（Descriptor），也就是裝置內建的自我介紹表，問出「你是誰、你要做什麼」的過程。完成後，作業系統才會依 VID / PID 與裝置類別載入驅動程式。按「下一步」看看 Host 和 Device 之間說了什麼。

07 · 傳輸類型

07四種傳輸類型

不同裝置對資料的要求不同：滑鼠要即時（低延遲），隨身碟要正確（錯了要重送），視訊要不中斷（要有穩定的頻寬）。所以 USB 定義了四種傳輸類型。點一張卡片，看它適合誰、保證什麼。

示意：一個 1 ms 的幀（全速）裡，Host 先排等時與中斷，再排控制，剩下的空間才給大量傳輸。
